# Nitin Captures - Responsive Pure CSS Sidebar Navigation

A sleek, responsive, and interactive navigation menu overlay built with **pure HTML5 and CSS3**. This project showcases modern UI design principles like glassmorphism and smooth micro-interactions—all implemented without writing a single line of JavaScript.

## ✨ Features

* **Zero JavaScript:** Employs the **CSS Checkbox Hack** (`<input type="checkbox">` & `:checked` pseudo-class) to manage the open/close state.
* **Glassmorphism UI:** Features translucent background layers, custom box shadows, and blurred aesthetics for a modern look.
* **Smooth Micro-Interactions:** Custom hover scaling for action buttons, links, and social media icons.
* **Fully Custom Typography:** Integrated with Google Fonts (`Poppins`) and Font Awesome 6 icons.
* **Responsive Layout:** Fixed overlay system designed for smooth sliding across desktop and mobile viewports.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic layout structure.
* **CSS3:** Flexbox, absolute/fixed positioning, custom transitions, and CSS pseudo-classes (`:checked`, `:hover`).
* **Font Awesome 6:** Vector icons for navigation items and social media channels.
* **Google Fonts:** Custom font styling via `Poppins`.
